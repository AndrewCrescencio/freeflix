### Fontes recomendadas para assets reais:
1. **Unsplash** (gratuito, comercial) - fotos de cinema, TV, streaming
2. **Pexels** (gratuito, comercial) - similares
3. **The Movie Database (TMDb) API** - posters oficiais (requer licença para uso comercial)
4. **JustWatch / TMDB** - posters mediante parceria
5. **Estúdios/distribuidoras** - licenciamento direto para títulos específicos
6. **Fotógrafos/designers contratados** - arte original exclusiva

### Especificações técnicas para produção:
- **Posters:** 400x600px (2:3), AVIF/WebP, < 50KB cada
- **Hero bg:** 1920x1080px, AVIF/WebP, < 200KB
- **OG image:** 1200x630px, PNG/WebP, < 300KB
- **Favicon:** 32x32 SVG + 192/512 PNG para PWA

### Checklist legal:
- [ ] Todos os posters têm licença para uso comercial em streaming

- [ ] OG image usa apenas elementos próprios/licenciados
